# Game

Initial scaffold for Godot project.

## Getting started

1. Install Godot 4.7.2 (or a matching version).
2. Open this folder as a Godot project (create `project.godot` if missing).
3. Install export templates in Godot: Editor → Manage Export Templates.

## Quick start

1. Install Godot 4.7.2 and ensure `godot` is on your PATH.
2. Open the project folder in Godot Editor and set `main.tscn` as the main scene.
3. Run the project. Controls: WASD / Arrow keys to move. Interact by approaching the heirloom.

Command-line run:
```
godot --path . -s main.tscn
```
