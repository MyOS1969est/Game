# Game

Initial scaffold for Godot project.

## Getting started

1. Install Godot 4.7.2 (or a matching version).
2. Open this folder as a Godot project (create `project.godot` if missing).
3. Install export templates in Godot: Editor → Manage Export Templates.

## Setup commands

```powershell
# Optional: install Git LFS and GitHub CLI via winget
winget install --id Git.GitLFS -e --source winget
winget install --id GitHub.cli -e --source winget
```
